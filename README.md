# Netflix Sign-In Page Clone

A frontend recreation of the Netflix sign-in interface built as a web-development practice project.

## Overview

This project recreates the visual structure and interaction of a Netflix-style sign-in page using HTML, CSS, and JavaScript.

The project was created to practise frontend development fundamentals, including responsive layout, styling, form elements, and basic client-side interaction.

## Features

* Netflix-inspired sign-in interface
* Responsive layout
* Form inputs
* Custom styling
* Basic JavaScript interaction

## Technologies

* HTML5
* CSS3
* JavaScript
